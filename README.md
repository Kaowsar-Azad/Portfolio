## 🛠️ Technologies & Tools

This portfolio is built using cutting-edge web technologies to ensure a fast, smooth, and visually stunning user experience:

*   **Next.js (v16+):** The core framework powering both the frontend and backend, enabling blazing-fast load times and optimized performance.
*   **React (v19):** Used to build the dynamic and interactive User Interface (UI) components (like buttons, cards, and navigations).
*   **Tailwind CSS:** Utility-first CSS framework utilized for crafting the modern design, vibrant colors, layout, and seamless mobile responsiveness.
*   **Framer Motion:** Implemented to bring the website to life with beautiful, smooth, and professional animations (e.g., sliding text and images).
*   **Lenis:** Integrated to provide a buttery-smooth scrolling experience from top to bottom.
*   **React Parallax Tilt:** Added to create engaging 3D tilt effects on cards and images when the user hovers over them.
*   **React Intersection Observer:** Used to trigger specific animations precisely when a user scrolls into a particular section of the page.
*   **React Icons:** Utilized for rendering crisp, scalable vector icons (social media, menus, contact icons) throughout the website.
